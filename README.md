# ChatApp - Aplikasi Obrolan Real-Time MERN Stack

Aplikasi obrolan waktu nyata berbasis web. Proyek ini menggunakan arsitektur MERN (MongoDB, Express, React, Node.js) dan terintegrasi dengan Socket.io untuk komunikasi dua arah yang instan.

## 🚀 Fitur Utama
* **Autentikasi Aman:** Sistem pendaftaran, masuk, dan keluar menggunakan JSON Web Token (JWT).
* **Pesan Instan:** Kirim dan terima pesan tanpa perlu memuat ulang halaman (*real-time*).
* **Indikator Online:** Lihat daftar teman yang sedang aktif secara langsung.
* **Antarmuka Modern:** Desain antarmuka pengguna (UI) yang bersih, responsif, dan elegan.
* **Manajemen Status:** Penggunaan Zustand untuk mengelola memori global aplikasi di sisi klien.

## 🛠️ Teknologi yang Digunakan
* **Frontend:** React (TypeScript), Tailwind CSS, DaisyUI, Zustand, React Router DOM.
* **Backend:** Node.js, Express.js, Socket.io.
* **Database:** MongoDB, Mongoose.

## 📦 Prasyarat Instalasi
Pastikan komputer Anda sudah terinstal perangkat lunak berikut:
* Node.js (versi 16 atau lebih baru)
* Akun dan klaster MongoDB (Atlas atau lokal)
